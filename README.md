# Personal Portfolio Web Application

## About the Project

This project is a responsive Personal Portfolio Web Application developed as part of the Full Stack Development assignment.

The portfolio presents my academic background, technical skills, projects, achievements, certifications, and contact information in a clean and responsive interface.

## Technologies Used

- HTML5
- CSS3
- Bootstrap
- JavaScript ES6+

## Portfolio Sections

- Home
- About Me
- Education
- Technical Skills
- Projects
- Achievements
- Certifications
- Contact

## Projects

### Automatic Fire Extinguisher
An automatic fire extinguisher project developed using Arduino and C programming.

### Calculator Application
A calculator application developed using Java GUI programming.

### Health Checkup Post Call GenAgent Devp
Developed during an internship at Purview Services.

## JavaScript Features

The portfolio includes the following interactive features:

- Project filtering by category
- Dark Mode / Light Mode theme switching
- Contact form validation with dynamic error and success messages

## Responsive Design

The website is designed to work across:

- Desktop
- Tablet
- Mobile devices

Bootstrap's responsive grid system, CSS media queries, Flexbox, and modern CSS styling are used to create the responsive layout.

## Accessibility

The portfolio uses semantic HTML elements, labels for form fields, accessible buttons, and dynamic messages for better usability.
